## 🚀 Installation & Développement

```bash
# Clone du repository
git clone https://github.com/CVanzetta/Portfolio.git
cd Portfolio

# Installation des dépendances
npm install

# Lancement du serveur de développement
npm run dev

# Build de production
npm run build
```
